# ATHEER DEV TEAM — Foundation UI

واجهة تأسيسية مستقلة لفريق تطوير أثير، داخل نفس مستودع الموقع الرسمي.

## التشغيل
افتح `index.html` في المتصفح أو افتح المسار `/dev-team/` بعد نشر ملفات المستودع.

## الحالة الحالية
- واجهة ثابتة مبنية بـ HTML وCSS وJavaScript دون إطار عمل إضافي.
- نموذج إنشاء المهام يحفظ مسودات مؤقتة في ذاكرة الصفحة فقط.
- لا يوجد اتصال فعلي مع ChatGPT أو Gemini أو GitHub API.
- لا توجد عمليات تنفيذ كود أو commits أو نشر من هذه الواجهة.
- شارات الحالة توضح أن الوكلاء غير مربوطين بعد.

## حدود الأمان
لا تضف مفاتيح API أو GitHub tokens إلى ملفات المتصفح. يجب تنفيذ الربط مستقبلاً عبر خادم خلفي موثوق، مع صلاحيات محدودة، وسجل تدقيق، ومراجعة بشرية قبل الدمج إلى `main` أو النشر الإنتاجي.

## مسار التطوير
1. اعتماد تجربة الواجهة.
2. تصميم backend آمن لتنسيق الطلبات بين ChatGPT وGemini.
3. إضافة مصادقة وصلاحيات GitHub محدودة للفرع المخصص.
4. تشغيل الاختبارات والمراجعات وإنتاج Pull Request.
5. إبقاء الدمج والنشر خلف موافقة المالك.
