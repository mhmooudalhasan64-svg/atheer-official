# ATHEER DEV TEAM — Backend foundation

واجهة مستقلة لفريق تطوير أثير داخل المستودع نفسه، مع أول نقطة API على Vercel.

## نقطة الفحص
- المسار: `GET /api/health`
- يردّ بحالة الخدمة وإصداره وحالة تكاملات ChatGPT وGemini وGitHub.
- لا يعرض أسراراً أو متغيرات بيئة.
- يدعم `HEAD`، ويرفض بقية الطرق بـ `405`.
- لا يستخدم قاعدة بيانات أو أي خدمة مدفوعة.

## الحالة الفعلية
- واجهة اللوحة ثابتة بـ HTML وCSS وJavaScript.
- نقطة فحص API مضافة عبر Vercel Functions.
- اللوحة تفحص نقطة API وتعرض حالة الاتصال.
- مسودات المهام ما زالت في ذاكرة الصفحة فقط؛ لا يوجد تخزين دائم.
- لا يوجد اتصال فعلي مع ChatGPT أو Gemini أو GitHub API.
- لا توجد عمليات تنفيذ كود أو commits أو نشر من هذه الواجهة.

## لماذا لم نفعّل حفظ المهام بعد؟
المستودع لا يحتوي قاعدة بيانات أو مخزن مهام. استخدام ذاكرة Function وحدها غير موثوق لأن Vercel قد يشغّل نسخاً متعددة أو يعيد تشغيلها. لذلك لن نعرض حفظاً دائماً وهمياً. الخطوة التالية هي اعتماد مخزن دائم مع حماية اللوحة قبل فتح استقبال المهام.

## الأمان
- لا تضع مفاتيح API أو GitHub tokens في ملفات المتصفح أو المستودع.
- يجب حماية واجهة المهام بمصادقة قبل استقبال أي طلبات فعلية.
- صلاحيات GitHub يجب أن تكون محدودة بفرع التطوير.
- الدمج إلى `main` والنشر الإنتاجي يظلان خلف موافقة المالك.

## مراحل التنفيذ
1. نقطة فحص API — مكتملة.
2. اعتماد تخزين دائم ومصادقة للوحة.
3. إنشاء API للمهام وتسجيل مراحلها.
4. ربط ChatGPT وGemini عبر الخادم بعد إعداد المفاتيح بشكل آمن.
5. ربط GitHub بفرع التطوير، ثم الاختبار والمراجعة.
6. إبقاء الدمج والنشر خلف موافقة المالك.
