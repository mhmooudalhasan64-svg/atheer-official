# أثير | ATHEER — الموقع الرسمي

الموقع الرسمي لشركة أثير، بهوية عربية واتجاه بصري يعتمد الأسود العميق والذهبي الملكي والعاجي.

## تشغيل محلي
افتح ملف `index.html` في المتصفح، أو استخدم أي خادم ملفات ثابتة.

## النشر على Vercel
- إطار العمل: Other
- مجلد الجذر: `./`
- أمر البناء: اتركه فارغاً
- مجلد الإخراج: اتركه فارغاً أو استخدم `./`

## ملاحظات ما قبل الإطلاق
- الرمز الحرفي في رأس الموقع عنصر مؤقت وليس الشعار الهندسي النهائي المعتمد.
- رابط البريد في قسم التواصل يحتاج إلى استبداله بعنوان أثير الرسمي قبل الإطلاق.
- راجع روابط المنتجات والمحتوى التعريفي قبل النشر العام.
- المشروع صفحة ثابتة ولا يحتاج حالياً إلى خادم خلفي أو قاعدة بيانات.
